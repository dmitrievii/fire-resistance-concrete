# R0.5.6 — расчётные модели и происхождение результатов

## Цель

Вычислительные блоки для нескольких железобетонных колонн, нескольких расчётных сечений на колонну и автоматизированного отчёта. Старый клиентский DOCX и XMCD не включены в публичный GitHub.

## Что является проверенным воспроизведением Mathcad

`calculation_engine.py` хранит точно воспроизведённый исторический расчёт К18 для **фиксированных** данных, включая 44 контрольных скаляра из оригинального XMCD при предыдущей проверке. Это не универсальный алгоритм для произвольной геометрии. Он не заменён новым волоконным решателем и служит численным эталоном регрессии. Отдельное совпадение с Mathcad не означает нормативную квалификацию исходной методики.

## Что обобщено для произвольной колонны

`parametric_engine.py` (R0.4) восстанавливает четырёхстороннюю формулу нагрева К18, рассчитывает температуру **каждого** стержня, его k(T)/β(T), строит дискретное эффективное бетонное сечение по изотерме 500 °C и находит сопротивление в плоскостях X/Y. Его волоконная диаграмма — самостоятельное численное допущение, а не дословный Mathcad.

`r056_engine.py` добавляет:

- общую оценку устойчивости `η = 1 / (1 − Nmax / Ncr,min)` по всем рассчитанным сечениям; это консервативный диагностический конверт, **не** решение нелинейного дифференциального уравнения прогиба всей колонны;
- одновременное решение трёх уравнений равновесия `N, Mx, My` по гипотезе плоских сечений, с учётом температурных характеристик стержней, отсечения растяжения бетона, ограничения напряжений и εc,max; при отсутствии сходимости выдаётся `equilibrium_not_found`, а не `PASS`;
- вычисление критерия хрупкого разрушения `F` по формуле 3.4.1 **эталонного отчёта**, `F=(αF·αbt·β·Ec·ρ·Wэ)/(K1C·λ²·np)`; порог `F>4` требует защитных мероприятий согласно тексту отчёта; все 9 коэффициентов должны быть предоставлены явно, без подразумеваемых нормативных значений;
- отдельно сохраняемые `provenance`, `member`, `biaxial`, `spalling` и `fire_resistance_status` в JSON.

## Контроль применимости

- Бетон/арматура, нормативные приоритеты и ограничения новых моделей **не прошли полного независимого аудита**.
- Отдельная проверка равновесия N–Mx–My не эквивалентна нормативной проверке двухосной несущей способности или устойчивости.
- `η_member` — единая величина по максимуму N и минимуму Ncr, но не пространственно связанный расчёт прогиба.
- Критерий `F` вычисляет только индекс по заданным коэффициентам. Отсутствие параметра означает `not_evaluated`, а не благоприятное значение.
- **Приложение не выдаёт нормативный вывод R90** для произвольной колонны на основании нового решателя. В отчётах все ограничения сохраняются.

## UI и отчёты

- Страница конструкции: редактирование 9 коэффициентов F; общий конверт, совместное равновесие и F.
- Обзор: статусы проверки для каждой колонны, синхронизация с общей проектной моделью.
- Индивидуальный и общий DOCX: дополнительный расчётный раздел R0.5.6; исторические рамки/штампы сохраняются из обезличенного мастер-шаблона.
- Пустые нагрузки/коэффициенты никогда не заменяются нулём для формирования положительного вывода.

## Приёмочные тесты

`python -m unittest discover -s tests -v` + `tests/test_r056.py`: регрессия К18, бивалентный (совместный) случай, несимметричная схема стержней, геометрия, большие моменты, Nmax по нескольким сечениям, отсутствие F, редактирование F, нулевые/незаполненные усилия, запрет ложной сертификации, генерация DOCX.
