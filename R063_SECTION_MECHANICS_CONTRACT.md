# R0.6.3 — Совместная механика нагретого сечения N–Mx–My

**Релиз:** `R0.6.3-section-mechanics-v1`  
**Состояние:** `NUMERICAL_SECTION_MODEL_IMPLEMENTED; SECTION_ULS_NOT_QUALIFIED; R90_BLOCKED`  
**Нормативный приоритет:** только СП 2.02.05-2026 и СП 5.03.01-2020. Устаревший Mathcad К18 используется для регрессии, не для определения актуальных расчётных коэффициентов.

## 1. Назначение и границы

В R0.6.3 добавлен самостоятельный вычислительный модуль `rc_fire/mechanics` для **первого порядка** и **отдельного сечения** железобетонной колонны произвольного прямоугольного сечения с фактическими координатами каждого продольного стержня. На вход поступают температурное поле приложения К (R0.6.2), классы бетона и арматуры, свойства по R0.6.1, и полная тройка внешних усилий N, Mx, My.

Результаты: внутренние N, Mx, My; их невязки; распределение деформаций и напряжений в бетоне/арматуре; индивидуальные эффекты снижения прочности; контроль предельных деформаций; матрица касательной жёсткости 3×3. Отдельно реализован **исследовательский**, не квалифицированный контур предельного сопротивления Mx–My при заданном N по дискретизации граничных деформаций.

**Не включено**: расчёт устойчивости элемента с пространственным вторым порядком, предварительное напряжение, ползучесть во время пожара, температурное стеснение и связанные усилия, локальный откол/spalling, сцепление, сдвиг, перераспределение усилий по длине, расчёт времени достижения R(t), квалифицированный критерий `PASS R90`.

## 2. Нормативные зависимости (источники: предоставленные пользователем PDF)

### 2.1 Коэффициенты расчётной ситуации

СП 5.03.01-2020, таблица 4.6, особая расчётная ситуация: `γc=1.20`, `γs=1.00`.

СП 5.03.01-2020, (6.4), (6.5), (6.28):

\[
\alpha_{cc}=\min\{1,(40/f_{ck})^{1/3}\},\qquad
f_{cd}=\frac{\alpha_{cc} k_{tc}f_{ck}}{\gamma_c},\qquad
f_{yd}=\frac{f_{yk}}{\gamma_s}.
\]

`k_tc=1.0` — рекомендуемое значение пункта 6.1.2.11; происхождение хранится явно. Для C30/37 и S500 получаем `f_cd(20)=25 MPa`, `f_yd(20)=500 MPa`.

### 2.2 Температурные свойства

СП 2.02.05-2026, п. 8.2.18, таблицы 9 и 10:

\[
f_{cd,\theta}=k_c(\theta)f_{cd},\quad E_{cm,\theta}=\beta_c(\theta)E_{cm},\quad
f_{yd,\theta}=k_s(\theta)f_{yd},\quad E_{s,\theta}=\beta_s(\theta)E_s.
\]

Температура **каждого бетонного волокна** получается из приложения К с численной сеткой, температура арматуры — из того же приложения с фактическими координатами/диаметрами. Каждая интерполяция по табличным температурам — отдельное численное соглашение. Таблицы заканчиваются при 800 °C: при **любой температуре выше 800 °C** нормативный маршрут останавливается без экстраполяции. Режим `zero_strength_diagnostic`, требующий явного выбора, назначает *нулевую* прочность перегретым волокнам и **не является нормой**.

Для арматуры таблица 10 начинается при 200 °C; интерполяция от нормальных свойств при 20 °C до первой точки таблицы 10 помечена `engineering_bridge_20_200_not_tabulated`.

### 2.3 Диаграмма бетона (СП 5.03.01-2020, (6.17), (6.18))

При сжатии `εc > 0`:

\[
\sigma_c=f_{cd,\theta}\bigg[1-\bigg(1-\frac{\varepsilon_c}{\varepsilon_{c2}}\bigg)^n\bigg],
\qquad 0<\varepsilon_c<\varepsilon_{c2};
\]
\[
\sigma_c=f_{cd,\theta},\qquad
\varepsilon_{c2}\leq\varepsilon_c\leq\varepsilon_{cu2}.
\]

Напряжения растянутого бетона принимаются равными нулю (п. 8.1.2.1). `εc2`, `εcu2`, показатель `n` — таблица 6.1 СП 5.03.01-2020. **Численное допущение:** их значения при нагреве пока не изменяются, так как §8.2.18 и таблица 9 непосредственно задают `kc` и `β`, но не отдельные температурные значения предельных деформаций. Для решения Ньютоном напряжение на пробных состояниях `ε>εcu2` формально остаётся на площадке, однако соответствующий результат **отклоняется** контролем предельных деформаций.

Различаем `βc Ecm` как табличную характеристику для анализа жёсткости и фактический касательный модуль диаграммы (6.17) при текущем уровне деформации. Они **не тождественны**, и в R0.6.3 не подменяются друг другом.

### 2.4 Диаграмма арматуры

СП 5.03.01-2020, п. 6.2.2.13: двухлинейная диаграмма с горизонтальной площадкой:

\[
\sigma_s=\operatorname{clip}(E_{s,\theta}\varepsilon_s,-f_{yd,\theta},f_{yd,\theta}).
\]

Предел деформации растянутой арматуры для проверочного расчёта — 10‰ (п. 8.1.2.1). Наличие равновесия после достижения этого предела **не** считается допустимой работой сечения.

## 3. Совместная модель сечения

Плоские сечения, СП 5.03.01-2020 п. 8.1.2, (8.1)–(8.3). Приняты знаки: положительная N — сжатие; Mx сжимает грань +y, My — грань +x. Модель реализует одну систему, а не две несвязанные проверки:

\[
\varepsilon(x,y)=\varepsilon_0+\kappa_x(y-y_c)+\kappa_y(x-x_c)
\]
\[
N=\int_{A_c}\sigma_c\,dA+\sum_i (\sigma_{si}-\sigma_{ci})A_{si},\qquad
M_x=\int_{A_c}\sigma_c(y-y_c)\,dA+\sum_i(\sigma_{si}-\sigma_{ci})A_{si}(y_i-y_c),
\]
\[
M_y=\int_{A_c}\sigma_c(x-x_c)\,dA+\sum_i(\sigma_{si}-\sigma_{ci})A_{si}(x_i-x_c).
\]

`σsi − σci` вычитает бетон, физически вытесненный арматурой, из интеграла по полной площади сечения. Решается одна система для `ε0, κx, κy` демпфированным методом Ньютона с вычисленным аналитическим Якобианом и контрольными невязками. Две оси проходят один и тот же численный метод.

**Техническая оговорка:** успешная сходимость трёх уравнений и соблюдение локальных предельных деформаций ещё не являются нормативной оценкой несущей способности всей колонны. Для этого необходима квалифицированная граница ULS и эффекты второго порядка.

## 4. Численный контур сопротивления (не нормативная квалификация)

Модуль `capacity.py` при фиксированной N дискретизирует ориентации градиентов деформаций (24–144 направлений), находит состояния с предельными деформациями бетона/растянутой арматуры и интерполирует полигон `Mx–My` для оценки радиального коэффициента `u≈`. Доступен на странице конкретной колонны **только при явном выборе пользователем**. По умолчанию эта процедура **не** участвует ни в результате R90, ни в общих сводных коэффициентах. Шаг дискретизации и оптимизационная процедура являются исследовательскими; до независимой нормативной верификации нельзя трактовать `u≈ < 1` как положительный вывод.

## 5. Реестр границ применимости

| Условие | Выполнение |
|---|---|
| Реальный прямоугольный контур, явные стержни | Да |
| 1–4 нагреваемые стороны, приложение К | Да, при действительности формулы и поля |
| Нормативно разрешённые материальные характеристики | Да; при отсутствии — `blocked` |
| Все температуры ≤800 °C | Основная ветвь; без экстраполяции |
| Любые температуры >800 °C | `blocked`; опционально `zero_strength_diagnostic` |
| Сталь 20–200 °C | Отдельно обозначенная инженерная интерполяция |
| Высокопрочные бетоны без `βc` таблицы 9 | `blocked` |
| Допущение о неизменных εc2, εcu2 при нагреве | Явно обозначено, требует квалификации |
| Тепловые собственные деформации / температурное защемление | Не включены в локальный ULS |
| Расчётное сочетание нагрузок по СН 2.01.03-2019 | Не реализовано; допускаются только заданные извне N/M |
| Пространственная устойчивость, вторые порядки, R(t) | Этапы R0.6.4 и далее |
| Положительный вывод по R90 | **Всегда запрещён** |

## 6. Тестирование и приёмка

Новые автоматические тесты `test_r063_mechanics.py` и `test_r063_capacity.py` проверяют:

1. Табличные коэффициенты особой расчётной ситуации и формулы (6.4), (6.5), (6.28).
2. Узловые значения диаграмм (6.17), (6.18) и стали с площадкой текучести.
3. Аналитически проверяемую одноосную равномерную деформацию и вычитание вытесненного бетона.
4. Одновременное решение N–Mx–My, разворот знаков, контроль невязки и аналитического Якобиана.
5. Сходимость по дискретизации бетонного сечения.
6. Уменьшение сопротивления при нагреве.
7. Запрет экстраполяции выше 800 °C и явную маркировку исследовательского `zero_strength_diagnostic`.
8. Отсутствие неизвестных свойств/неполных нагрузок без выдуманных нулей.
9. Устойчивость численного контура к изменению угловой дискретизации и масштабированию моментов.
10. Отсутствие `normative_claim=True` даже при сходимости и `u≈<1`.
